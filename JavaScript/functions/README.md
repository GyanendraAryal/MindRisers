## 💡 How to Use This Kit

1. **Read the cheatsheet** before each new concept group.
2. **Attempt every problem** — even if stuck, try for 15 min first.
3. **No copy-paste** from solutions. Type every character.
4. **Reflection questions** at the end of each set — answer in writing.
5. **Re-do problems after 3 days** without looking. If you can do it, you own it.
