#Methods in Array

#Adding and Removing Elements
    #1. push(): Adds one or more elements to the end of an array.
    #2. pop(): Removes the last element and returns it.
    #3. shift(): Removes the first element of an array.
    #4. unshift(): Adds one or more elements to the beginning.
    #5. splice(): A versatile method that can add or remove elements at any 
        specific index. 

#Data Transformation and Searching
    #1. map() / filter(): Create new, transformed or filtered arrays.
    #2. reduce(): Reduces an array to a single value.
    #3. find() / findIndex(): Locate elements or their indices based on tests.
    #4. includes() / indexOf(): Check for existence of values.
    #5. some() / every(): Test if any or all elements meet a condition.-used rearly

#Other Key Methods
    #1. forEach(): Iterates through elements.
    #2. sort(): Organizes array elements.
    #3. slice(): Creates shallow copies of portions of an array.
